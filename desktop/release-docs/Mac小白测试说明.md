# 银子AI视频工作流 V0.1.3 beta.4：Mac 小白测试说明

## 1. 选择正确版本

点击左上角苹果菜单，选择“关于本机”：

- 显示“芯片 Apple M1/M2/M3/M4...”时，使用文件名带 `mac-arm64` 的 DMG；ZIP 是备用。
- 显示“处理器 Intel”时，使用文件名带 `mac-x64` 的 DMG；ZIP 是备用。

选错版本时不要继续测试，重新下载对应架构即可。

## 2. 安装与首次打开

1. 双击 DMG，验证窗口正常打开，再把“银子AI视频工作流”拖到“应用程序”。若使用 ZIP，解压后把 `.app` 拖到“应用程序”。
2. 已签名/公证版本可直接双击。未签名内测版首次不要直接双击，按住 Control 点击应用，选择“打开”，在提示中再次点“打开”。
3. 如果仍被拦截，打开“系统设置 -> 隐私与安全性”，在安全提示旁点“仍要打开”，然后按系统提示确认。不要关闭整个 Gatekeeper，也不要执行来源不明的终端命令。

## 3. 建议测试顺序

1. 首页能正常显示，先点“模拟体验”；它不调用 API，也不会产生费用。
2. 打开“配置”，验证已保存配置的测试按钮；没有自己的 Key 时跳过真实生成。
3. 新建一个测试项目，确认关闭并重新打开应用后项目仍存在。
4. 在素材库查看演示图片，确认缩略图与原图可显示。
5. 打开 3D 导演台，确认画面非空、拖动和预演正常。
6. 有 API 配置时再测试一条真实任务；测试视频最终合成、旁白、字幕和下载。

## 4. 反馈时提供什么

请说明 Mac 型号、芯片、macOS 版本、使用的 DMG/ZIP 文件名、出错步骤和截图。启动日志位于：

`~/Library/Application Support/银子AI视频工作流/logs/desktop-startup.log`

后端日志位于：

`~/Library/Application Support/银子AI视频工作流/backend/logs/app.log`

日志可能包含作品名称和本地路径，公开发送前请先检查；不需要提供 API Key。

## 5. 卸载

把“银子AI视频工作流.app”移到废纸篓即可。作品和配置默认保留在上述 Application Support 目录。只有明确不再需要任何本地作品、素材和配置时，才手动删除该数据目录。
