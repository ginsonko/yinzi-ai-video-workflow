# 银子 AI 视频工作流：通用版 / 老李兼容版

## 你拿到的是什么

这个发行包不要求 YinziAPI 智能路由，也不会把银子 API 作为前置条件。第一次打开后，首页会明确引导你配置文本、图片、视频三个服务；如果你使用老李站点，点击“配置老李站点（三 Key）”即可一次创建文本、图片、分镜图和视频四项配置。

## 三步开始

1. 双击安装版完成安装，或直接双击 Portable 便携版运行。
2. 首次打开先点“模拟体验”熟悉完整流程；模拟不会调用 API，也不会扣费。
3. 真实制作时，在“AI 配置”中点击“配置老李站点（三 Key）”：图片 Base URL 和视频 Base URL 默认是 `https://video.laoliimage2.win/v1`；文本 Base URL 必须填写其它兼容 OpenAI Chat Completions 的文本站点。然后分别填写文本、图片、视频 Key，保存即可。

老李站点的模型映射已预置：`3.5` = 即梦 2.5，供应商请求固定 30 秒；`3.0` = 即梦 2.0，可请求 5、10、15 秒。图片 Key 同时用于图片和分镜图，三个 URL 与 Key 不会串用。能力提示不会限制你手动选择未知模型；如果上游拒绝，页面会显示真实原因和下一步建议。

## 使用其它 NewAPI / sub2 站点

保存老李配置后，可在配置列表分别编辑文本、图片、分镜图、视频的 Base URL、Key、协议和模型。通用版不会显示 YinziAPI 智能路由入口，也不会把老李站点锁成唯一选择；你可以添加任意兼容 OpenAI 或异步视频协议的站点。

## 任务流程

输入故事或导入小说，选择人工审批、AI 审批或全自动。AI 审批会把打回理由带入下一次生成；全自动会在预算、资源不足或连续异常时才提示人工。刷新、关闭页面或重启不会丢失任务，已接单的上游任务不会因为改配置而重复提交。

## 数据与安全

作品、素材、配置和日志保存在 `%APPDATA%\\银子AI视频工作流`。导出配置不会包含 Key；安装、升级和卸载默认保留数据。连接测试使用只读探针，不生成图片或视频。

## 遇到问题

- 模型暂时不可用：编辑对应视频配置，选择其它模型后重试；当前实际模型和历史失败模型会分别显示。
- 下载失败：使用“重试下载”，不会重新创建已完成的上游任务。
- 需要查看旧步骤：点击历史阶段或“停止当前访问”，后台任务可继续运行。
- 启动日志：`%APPDATA%\\银子AI视频工作流\\logs` 及其 `backend\\logs` 子目录。
