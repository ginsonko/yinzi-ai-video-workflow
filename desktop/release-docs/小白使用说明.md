# 银子AI视频工作流 V0.1.3 Windows 验收版：小白使用说明

## 第一次打开

1. 双击“银子AI视频工作流”。安装版会创建桌面和开始菜单入口；便携版无需安装。
2. 首页先点“模拟体验”。它不调用任何 API，也不需要 Key，可以完整看懂剧本、资产、分镜、3D 预演、镜头视频和最终成片的审批流程。
3. 准备真实制作时，回到首页查看“配置状态”。银子 API 用户优先点“一键配置银子API”，只填写 Base URL 和一个通用 Key；默认会配置 `gpt-5.6-sol`、`gpt-image-2`，视频按每个镜头的预计总价自动选择最便宜的兼容模型。不同分组需要独立 Key 时再展开高级设置。
   - 配置保存后，列表中的“测试”会由本机后端使用已保存 Key，不需要再次粘贴。
   - 修改 Base URL 或模型但还不想保存时，点“测试当前填写”；Key 留空会沿用本机已保存值，新填 Key 只用于本次测试。
   - 图片、分镜图、视频和 TTS 使用只读连接探针，不生成媒体；文本配置只请求极少测试文本。
4. 所有必要项准备好后，点“开始制作”，输入故事或导入小说，选择人工审批、AI 审批或全自动模式。

## 三种模式

- 人工审批：每一步都可编辑、确认、打回、删除或新增，适合精细制作。
- AI 审批：AI 会自己评估、打回、修改和复审；连续失败达到上限才交给人。
- 全自动：从故事一路运行到旁白、字幕和最终成片，除预算、资源不足或连续异常外不打扰用户。

## 数据和升级

作品、素材、配置、备份和日志保存在 `%APPDATA%\银子AI视频工作流`。卸载、重装或升级程序不会删除这个目录。旧版 `LocalMiniDrama` 或 `localminidrama-desktop` 数据首次启动时会复制到新目录，源目录仍保留，并生成迁移回执。

## 旁白和本地合成

应用自带 FFmpeg/FFprobe，不要求另装。默认 Xiaoyi 是应用内置的 Edge Neural 在线音色：无需 Python，也不收取 API 费用，但合成时需要联网。3D 导演台在本机运行，可按任务选择完全关闭。

## 出错时

- 页面会保留失败原因和恢复操作；刷新或重启后可继续原任务。
- 启动失败会给出数据目录和日志位置。日志位于 `%APPDATA%\银子AI视频工作流\logs` 和其 `backend\logs` 子目录。
   - 视频模型临时不可用时，可在任务中的模型设置切换当前 Key 已发现的模型，也可手动填写目录外模型后重试。保存时会同时绑定当前视频配置和模型，旧失败模型只留在历史中；下载重试不会重新创建付费任务。
- 如果旧任务误报“未配置视频模型”，先确认首页或高级设置中的视频配置仍启用且包含 URL/Key，然后回到任务点“已处理，继续全自动”。beta.4 会优先恢复原配置绑定并清除旧提示，不会擅自换模型。
- 明确 4xx 且没有上游任务 ID 的视频提交会自动返还本地预留额度；超时、断线、5xx 或异常成功响应会显示为“待对账”，不要立刻重复提交，先按页面保留的请求号确认上游是否已经接单。
- 达到预算上限时只停止新提交，不删除已经生成的任何资产。
