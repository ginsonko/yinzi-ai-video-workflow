# 银子AI视频工作流 V0.1.3 内测版（0.1.3-beta.4）

本次提供 Windows x64 安装版/便携版，以及 macOS Intel x64、Apple Silicon arm64 的 DMG/ZIP。用户无需安装 Node.js、npm、Python、FFmpeg 或 FFprobe。

主要能力：从故事/小说生成剧本；角色、场景、道具资产及并发生图；逐镜分镜脚本和参考图；可选 3D 导演台预演；首尾帧连续性；视频模型自动路由和人工覆盖；人工、AI 审批、全自动三种模式；旁白、字幕、原声混音、最终剪辑；素材库、归档、预算账本、提示词包和配置备份迁移。

注意：AI 文本、生图、视频和 Edge Neural 语音均需要访问对应在线服务；仅模拟体验、3D 导演台和 FFmpeg 剪辑可以完全本地运行。首次打开不会自动调用付费接口。

Windows 数据目录为 `%APPDATA%\银子AI视频工作流`，macOS 数据目录为 `~/Library/Application Support/银子AI视频工作流`。卸载或删除应用默认保留用户数据。

## V0.1.3 beta.4 修复

- 视频提交状态明确区分未发送、上游拒绝、上游接单和结果不确定；刷新、重启与继续自动流程时不会把这些状态互相覆盖。
- 上游在创建任务前明确返回 4xx 且没有任务 ID 时，本地会自动返还本次预留金额、次数和秒数；重复恢复不会二次返还。
- 超时、断线、5xx、异常 2xx 或无任务 ID 的 2xx 不会自动退款或重试，而是保留为待对账，防止上游可能已经接单时重复扣费。
- 修复目标 Seedance 2.0 模型在银子 API 实际路由中误用“最多 1 张参考图”的默认协议；当前合同支持 9 图、3 音频和 5-15 秒。
- 失败详情保留请求号、模型、视频配置、参考包与提交判定，便于用户和客服判断是否应重试。

## V0.1.3 beta.3 修复

- 修复明明已经配置并选择视频模型，任务却误报“未配置视频模型”的绑定缺口。镜头保存时现在会把当前视频配置 ID 与模型一起持久化，实际派发不再退回旧配置。
- 用户手动选择的模型可直接提交给当前配置对应的上游；本地目录和能力提示不再充当人工选模门控。
- 历史任务若保存过视频配置或脱敏配置快照，可在“已处理，继续全自动”后自动恢复绑定并清除旧提示，不切换模型，不重复创建已有上游任务。
- 只有配置被删除、停用或确实缺少 URL/Key 时才停止，并明确告诉用户去哪里修复。

## V0.1.3 beta.2 新增

- 银子 API 一键配置只需 Base URL 和一个 Key；默认文本模型为 `gpt-5.6-sol`，默认生图模型为 `gpt-image-2`，视频按镜头预计总价自动选择最便宜的兼容模型。
- 已为当前特价视频分组的 10 个目标模型固化并验证时长、参考媒体数量、计费单位、价格和自动路由资格；模型目录仍会按当前 Key 只读同步。
- “模型与能力”入口可维护本地能力提示和自动路由授权。未登记模型、人工模型选择和参考包不会被本地协议门控。
- 自动路由不会把未知价格当免费，也不会静默使用昂贵破甲模型；用户随时可以手动覆盖实际派发模型。

## V0.1.3 beta.1 修复

- 修复上游视频已完成但本地下载失败后被误判为“生成失败”的问题。现在保留原任务 ID，只恢复取回，不会因为刷新、继续或重试下载再次扣费。
- 修复同一镜头重复派发、镜头 1 卡住和无法跳过的问题；镜头支持跳过、恢复、拆分和补拍，顺序会自动聚焦到下一个可处理镜头。
- 资产图支持可配置并发的拖放批量上传与内容哈希去重；镜头仍按依赖顺序推进。
- 视频配置可按当前 Key 只读发现模型目录，项目、阶段和单镜头支持覆盖；切换后不会回退到旧模型。
- 继续保留 3D 导演台可选、首帧/尾帧策略、旁白字幕、全自动和 AI 审批模式。

## V0.1.2 兼容修复

- 修复视频模型下架后，旧失败 action、旧参考包或刷新页面仍把真实派发锁在旧模型的问题。保存项目级或镜头级新模型后，未提交预留、失败和历史取消任务会被可追溯地替代；已有上游任务 ID 的请求继续轮询，不会重复扣费。
- 主状态同时展示当前配置、参考包模型和下一次实际派发模型；被替代的旧模型只保留在历史记录，不再冒充当前任务。
- 视频目录通过当前 Key 与公开价格目录只读同步；已知模型正确区分按次、按秒与固定时长计费。用户手动价格优先于自动目录价格，目录更新不会覆盖同键手动设置。
- 普通模型切换不再要求额外填写重试理由或授权；预算上限、明确的外部提交不确定性等真实风险仍会保留。
- 延续 V0.1.1 的配置测试修复：已保存 Key 由本机后端读取，图片、分镜图、视频和 TTS 连接测试不会创建媒体任务。

## macOS 发行说明

V0.1.3 beta.4 的 Intel 与 Apple Silicon 包由对应架构的真实 macOS runner 原生构建，并同时输出 DMG 与 ZIP。构建会实际加载 Better SQLite3 和 Sharp，验证主程序、FFmpeg 与 FFprobe 的架构和可执行性。当前产物未签名、未公证，首次打开需按 Mac 小白说明放行；GitHub 原生构建验收不等同于所有用户 Mac 的真机运行验收。
